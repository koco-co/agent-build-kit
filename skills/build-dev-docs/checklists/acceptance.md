# 内容验收

文件存在性和路径检查由验证工作流处理；本表只检查本次实际选择或更新的文档，未选择的职责不构成缺失。

- PRD 的范围、实体语义、阶段输入输出与状态转换能对应实际业务或确认的设计，正常路径及有依据的异常路径有验收条件。
- ARCHITECTURE 的分层、目录及允许和禁止的依赖一致，决策理由可追溯到 ADR 或已确认事实。
- GLOSSARY 的术语、含义、使用范围、别名与依据可定位，且术语在文档或代码中被实际使用；ID 的格式、生成规则和唯一性范围与 DATA_MODEL 及有效实现一致；未知依据已标注待确认。
- DATA_MODEL 的字段、关系与有效 Schema / 实现一致，ID 与 GLOSSARY 的定义一致；冲突已单列。
- ROADMAP 覆盖确认范围，每个任务有依赖、可判断的 Definition of Done；完成勾选有证据，计划没有冒充历史。
- 编码规范来自已有工具和项目模式或已确认约定；测试层次、覆盖预期与重试规则适合实际项目，没有套用固定覆盖率。
- 环境步骤包含执行目录、前置条件与准确命令，命令是否实际运行有说明；示例没有真实凭据。
- ADR 区分历史记录、本次确认和未知理由；CHANGELOG 的日期、实际变更与证据对应，没有生成虚构的工作会话。
- 风险、技术债与待确认事项说明影响，已知问题没有被擅自变成修复任务。
- AGENT_BRIEF 简短且反映当前状态，下一步和 ROADMAP 一致，详细规则通过索引读取。
- 提取模式清楚区分现状与目标、实现与验证；更新模式同步受影响的引用、状态及记录，未改变无关文档。
