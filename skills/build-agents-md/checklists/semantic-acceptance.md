# 内容审查清单

## 项目概览

- [ ] 每条规则都有用户需求、仓库事实、平台契约、可复现缺陷或明确安全要求依据；没有为未经证实的假设增加约定、兜底或校验。
- [ ] 前十行能说明项目是什么、主要入口和最关键边界。
- [ ] 仓库结构只包含会改变修改决策的路径。
- [ ] 根文件不套用通用模板文案也能准确描述当前项目。

## 事实与命令

- [ ] 每个项目事实都有仓库或用户决策证据。
- [ ] 每条命令可复制，并能追溯到脚本、配置、CI 或项目文档。
- [ ] 已运行与“来源已确认、运行未验证”没有混写。
- [ ] 没有虚构兼容性、测试结果、发布状态或环境能力。

## 规则质量

- [ ] 每条关键约定都是项目特有，删除后会增加具体错误风险。
- [ ] 通用 Agent 行为、教程、宣传和重复 README 内容已排除。
- [ ] 详细说明优先链接到仓库已有文档，没有为本 Skill 新建项目级 `docs/`。
- [ ] 超过软长度预算的内容已逐项证明必要，或已删减、链接、下沉。

## 目录与平台

- [ ] 每个嵌套 `AGENTS.md` 都有独立技术栈、命令、边界或规则理由。
- [ ] 嵌套正文只补充与根文件不同的内容，没有复制根文件。
- [ ] `CLAUDE.md` 是只包含 `@AGENTS.md` 的普通文件，且由脚本校验。
- [ ] 平台专有旧规则已泛化、显式保留或经用户确认移除，没有静默丢失。

## 范围与证据

- [ ] 写入内容与用户明确请求或已确认的完整内容预览一致。
- [ ] 没有修改授权范围之外的项目文件或覆盖不相关未提交工作。
- [ ] 静态校验、项目命令和真实目标客户端（Claude Code、Codex、ZCode、Pi 或 DeepSeek Harness 中实际可用的）加载证据分别报告。
- [ ] 未获授权时没有 commit、push、发布或更新本地 Plugin。
